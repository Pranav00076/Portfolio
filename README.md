This is my **developer portfolio website**, designed as a journey across the **Grand Line of Technology**. The site combines modern web development with a fun adventure theme inspired by *One Piece*, showcasing my projects, skills, and experiences.

# ⚓ About the Project

This portfolio represents my journey as a **Software Engineer and Computer Science student**.  
Instead of a traditional portfolio layout, the site is built with a **story-driven adventure theme**, where visitors explore different sections of my work like islands in the Grand Line.

The goal was to create something that is:

- Professional  
- Interactive  
- Memorable  
- Reflective of my personality and interests  

---

# 🚀 Features

### 🧭 Adventure-Themed Navigation
